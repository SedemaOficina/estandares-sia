# Estándar de formularios web del SIA · v1.0.0

Paquete genérico de estilos, componentes, validaciones y reglas para construir formularios web del Sistema de Información Ambiental de la Secretaría del Medio Ambiente de la Ciudad de México.

**Empieza por [`LEEME.md`](LEEME.md)** y abre `guia-visual/index.html` en el navegador.

- Reglas (81, con nivel BASE / RECOMENDADO / OPCIONAL): [`docs/01-reglas.md`](docs/01-reglas.md)
- Qué pieza usar para cada pregunta: [`docs/03-guia-de-decision.md`](docs/03-guia-de-decision.md)
- Contrato HTML y módulos: [`docs/06-codigo-y-contrato-html.md`](docs/06-codigo-y-contrato-html.md)
- Antes de liberar un formulario: [`docs/08-verificacion-y-cierre.md`](docs/08-verificacion-y-cierre.md)
- Historial: [`CHANGELOG.md`](CHANGELOG.md)

```sh
npm install        # sólo herramientas de verificación; el estándar no tiene dependencias
npm run verificar  # auditor, contraste, campos, bibliotecas, documentos y pruebas en navegador
```
